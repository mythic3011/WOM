# Mock Image Assets

This directory contains placeholder images for development and testing.

## Directory Structure

- `performances/` - Performance poster images
- `profiles/` - User profile images

## Naming Convention

### Performance Images

- Format: `perf-{number}.jpg`
- Example: `perf-1.jpg`, `perf-2.jpg`, etc.

### Profile Images

- Format: `prof-{number}.jpg`
- Example: `prof-1.jpg`, `prof-2.jpg`, etc.

## Usage

These images are used by the mock data generators during database seeding.
The seed script will randomly or cyclically select from available images.

## External Placeholders

For development, the system uses placeholder.com URLs when local images are not available.
